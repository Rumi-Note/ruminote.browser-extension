# Rumi书摘 · 微信读书同步

在微信读书网页版打开一本书，点击浏览器右侧的 Rumi书摘，即可集中查看当前书籍的全部书摘和想法，并一键同步到 Rumi书摘。

> 本扩展不是微信读书官方工具。它不会读取、保存或上传微信读书 Cookie，也不会解析书籍正文，只读取你自己在“我的笔记”中的书摘和想法。

## 安装

从 [`releases/`](releases/) 目录下载对应浏览器的安装包，解压后按下面步骤加载。无需自己构建。

### Chrome / Edge

1. 下载并解压 `ruminote-weread-chrome-v0.1.0.zip`。
2. 在地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压出的文件夹。
5. 建议把 Rumi书摘固定到工具栏。

### Firefox

1. 下载并解压 `ruminote-weread-firefox-v0.1.0.zip`。
2. 在地址栏打开 `about:debugging#/runtime/this-firefox`。
3. 点击“临时载入附加组件”。
4. 选择解压出的 `manifest.json`。

> Firefox 的临时加载会在重启后失效，重新加载即可。

## 使用前准备

1. 使用 Chrome、Edge 或 Firefox 打开微信读书网页版并登录。
2. 安装并启用 Rumi书摘扩展。
3. 打开一本书的阅读页面。
4. 如需同步，在 Rumi书摘小程序中准备一个六位配对码。

## 第一步：打开书摘侧栏

在微信读书阅读页点击工具栏中的 Rumi书摘图标，扩展会在浏览器右侧打开。

- 当前标签不是微信读书时，侧栏只显示“当前页面不是微信读书”和“打开微信读书”入口。
- 在微信读书站内但还没进入阅读页时，侧栏会提示先打开一本书。
- 进入书籍阅读页后，侧栏会自动开始读取书摘。

首次读取会短暂显示“正在读取书摘”，读取完成后提示会自动消失并展示书摘卡片。

## 第二步：检查书摘和想法

每条内容统一显示为“书摘”，不区分微信读书中的马克笔、波浪线或直线。

- 书摘正文显示在书页卡片中；
- 卡片底部显示章节名称；
- 微信读书“想法”显示在原文下方，并标记为“我的想法”；
- 相同原文的“想法”和独立书摘会作为两条记录分别保留。

如果页面声明的笔记总数与实际读取数量不一致，侧栏仍会展示已读取内容，但同步按钮会被禁用，以避免遗漏书摘。

## 第三步：绑定 Rumi书摘

第一次同步时：

1. 点击底部的“同步 N 条书摘”。
2. 在 Rumi书摘小程序中生成六位配对码。
3. 将配对码输入扩展侧栏。
4. 点击“绑定此浏览器”。

绑定成功后，扩展会自动继续你刚才发起的同步，无需再次点击。

## 第四步：完成同步

- 新同步的卡片会显示“已同步”；
- 底部会显示本次新增条数和已存在条数；
- 当前书籍没有新增内容时，按钮显示“已全部同步”；
- 后续只同步新增书摘，不会重复上传；
- 网络失败、额度不足或部分失败的批次不会被标记成功，下次可以重新同步。

## 数据与隐私

- 只读取当前书籍页面中你自己的“我的笔记”书摘节点。
- 只在你打开侧栏或点击刷新时读取。
- 不读取、保存或上传微信读书 Cookie，不解析书籍正文。
- 本地只保存 Rumi 设备令牌、设备 ID 和已同步书摘的指纹。
- 同步时上传的内容包括书名、作者、章节、书摘正文和你自己的想法。

## 常见问题

**一直显示“正在读取书摘”怎么办？**
在扩展管理页重新加载最新版扩展，再关闭并重新打开侧栏。

**为什么同步按钮不可点击？**
通常是当前书籍没有书摘，或读取到的数量少于微信读书声明的总数。点击右上角刷新重试。

**为什么需要配对码？**
配对码用于把这个浏览器安全地绑定到你的 Rumi书摘账号。扩展不会索取微信账号密码，也不会上传微信读书登录信息。

**会重复同步吗？**
不会。扩展只提交本地尚未成功标记的新增记录，服务端也会做幂等去重。
