# 上架任务

## STORE-001：将 Rumi书摘浏览器扩展上架应用商店

- **状态**：待开始
- **优先级**：P1
- **创建时间**：2026-09-10
- **目标版本**：v0.1.x
- **目标仓库**：Ruminote 微信读书浏览器扩展
- **前置条件**：微信读书读取、六位码绑定、增量同步链路已在 Chrome 本地验证通过

### 目标

将“Rumi书摘 · 微信读书同步”发布为用户可直接从浏览器应用商店安装和更新的正式扩展，不再要求用户开启开发者模式或手动加载 ZIP。

### 上架范围

首选商店：

1. Chrome Web Store
2. Microsoft Edge Add-ons
3. Firefox Add-ons（AMO）

根据账号准备情况，可先完成 Chrome，再复用素材提交 Edge 和 Firefox。

### 验收标准

任务满足以下条件后可标记完成：

1. 至少一个主流浏览器应用商店审核通过并可公开安装。
2. 商店页面包含完整产品说明、隐私政策、支持方式和脱敏截图。
3. 安装后的扩展能完成“打开微信读书 → 读取书摘 → 配对 → 增量同步”完整流程。
4. 发布版本、Git tag、安装包与商店版本号一致。
5. README 已从开发者模式安装说明切换为商店安装入口，并保留离线安装方式作为备用。

### 暂不包含

- 微信读书远端删除或修改同步。
- KOReader 与微信读书之间的双向同步。
- 自动后台上传；仍由用户主动点击同步。
- 对微信读书私有 API、Cookie 或正文 Canvas 的解析。
