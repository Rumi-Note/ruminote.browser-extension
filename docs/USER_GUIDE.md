# Rumi书摘 · 微信读书同步使用指南

Rumi书摘浏览器扩展可以读取你在微信读书网页版当前书籍中的书摘和想法，并在浏览器右侧集中展示。确认无误后，可由你主动同步到 Rumi书摘。

> Rumi书摘不是微信读书官方工具。扩展不会读取、保存或上传微信读书 Cookie，也不会读取书籍正文 Canvas。

## 使用前准备

1. 使用 Chrome 或 Firefox 打开微信读书网页版并登录。
2. 安装并启用“Rumi书摘 · 微信读书同步”扩展。
3. 打开一本书的阅读页面。
4. 如需同步，在 Rumi书摘小程序中准备一个六位配对码。

## 第一步：打开书摘侧栏

在微信读书阅读页点击浏览器工具栏中的 Rumi书摘图标，扩展会在浏览器右侧打开。

如果当前标签不是微信读书，侧栏只显示“当前页面不是微信读书”和“打开微信读书”入口，不会加载账号、书籍、书摘或同步功能。如果已经在微信读书站内但尚未进入书籍阅读页，侧栏会提示先打开一本书。切换到阅读页后，侧栏会自动开始读取。

侧栏顶部会显示：

- 当前书名和作者；
- 已读取的书摘数量；
- 账号绑定状态；
- 重新读取按钮。

扩展首次读取时会短暂显示“正在读取书摘”。读取完成后，该提示会自动消失并展示书摘卡片。

## 第二步：检查书摘和想法

每条内容统一显示为“书摘”，不区分微信读书中的马克笔、波浪线或直线样式。

- 书摘正文显示在白色书页卡片中；
- 卡片底部显示章节名称；
- 微信读书“想法”显示在原文下方，并标记为“我的想法”；
- 相同原文的“想法”和独立书摘会作为两条记录保留。

如果页面声明的笔记总数与实际读取数量不一致，侧栏仍会展示已读取内容，但同步按钮会被禁用，避免遗漏书摘。

## 第三步：绑定 Rumi书摘

第一次同步时：

1. 点击底部的“同步 N 条书摘”。
2. 在 Rumi书摘小程序中生成六位配对码。
3. 将配对码输入扩展侧栏。
4. 点击“绑定此浏览器”。

绑定成功后，扩展会自动继续刚才由你主动发起的同步，无需再次点击按钮。

## 第四步：完成同步

同步完成后：

- 新同步的卡片会显示“已同步”；
- 底部会显示新增条数和已存在条数；
- 当前书籍没有新增内容时，按钮显示“已全部同步”；
- 后续只同步新增书摘，不会重复上传已成功记录；
- 网络失败、额度不足或部分失败的批次不会标记成功，下次可以重新同步。

## 常见问题

### 一直显示“正在读取书摘”怎么办？

先在扩展管理页重新加载最新版扩展，再关闭并重新打开侧栏。修复后的版本会在书摘渲染完成后自动隐藏加载提示。

### 为什么同步按钮不可点击？

通常是因为当前书籍没有书摘，或扩展读取到的数量少于微信读书声明的总数。点击右上角刷新按钮重试。

### 为什么需要配对码？

配对码用于将这个浏览器安全地绑定到你的 Rumi书摘账号。扩展不会要求微信账号密码，也不会上传微信读书登录信息。

### 会重复同步吗？

不会。扩展只提交本地尚未成功标记的新增记录；服务端也会进行幂等去重。
