# 用户指南截图素材

将经过脱敏的真实使用截图放在本目录，并使用以下文件名：

- `01-notes-loaded-unbound.png`：书摘已读取、账号未绑定。必须使用加载提示已消失的修复后界面。
- `02-reader-with-synced-sidebar.png`：微信读书阅读页与侧栏并排，全部书摘已同步。
- `03-pair-code-dialog.png`：六位配对码输入界面。
- `04-incomplete-notes-warning.png`：读取数量不完整、同步按钮被禁用。
- `05-not-weread-page.png`：当前标签不是微信读书时的简洁入口提示。

截图要求：

1. 隐藏真实头像、昵称、配对码和其他账号信息。
2. 不出现浏览器 Cookie、开发者工具或接口令牌。
3. 优先保留完整侧栏边界，让用户理解它位于浏览器右侧。
4. 发布前确认书摘正文适合公开展示。
5. 图片建议使用 PNG，并控制在宽度 1600px 以内。

## 场景说明

### 场景 A：已读取书摘、尚未绑定（`01-notes-loaded-unbound.png`）

- 右侧侧栏展示当前书籍的书摘卡片；
- 右上角显示“未绑定”；
- 底部按钮显示“同步 N 条书摘”；
- 卡片使用暖米背景、暖白书页和金色引号。
- 说明文案：打开微信读书中的一本书，点击扩展图标，即可在右侧检查当前书籍的全部书摘。

### 场景 B：阅读页与侧栏并排、已全部同步（`02-reader-with-synced-sidebar.png`）

- 左侧为微信读书正文，右侧为 Rumi书摘侧栏；
- 顶部显示“已绑定”；
- 每张已同步卡片显示“已同步”，底部显示“已全部同步”。
- 说明文案：无需离开阅读页面即可查看同步状态，已同步书摘会被标记，后续只同步新增内容。
- 适合作为产品主页或帮助中心首图。

## 建议的帮助页配图顺序

1. 阅读页与侧栏并排；
2. 书摘卡片和“我的想法”；
3. 六位配对码输入界面；
4. 同步完成后的“已同步”状态；
5. 读取不完整、网络失败等可恢复提示。
