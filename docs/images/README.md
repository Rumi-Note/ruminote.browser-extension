# 用户指南截图素材

将经过脱敏的真实使用截图放在本目录，并使用以下文件名：

- `01-notes-loaded-unbound.png`：书摘已读取、账号未绑定。必须使用加载提示已消失的修复后界面。
- `02-reader-with-synced-sidebar.png`：微信读书阅读页与侧栏并排，全部书摘已同步。
- `03-pair-code-dialog.png`：六位配对码输入界面。
- `04-incomplete-notes-warning.png`：读取数量不完整、同步按钮被禁用。
- `05-not-weread-page.png`：当前标签不是微信读书时的简洁入口提示。

截图要求：

1. 隐藏真实头像、昵称、配对码和其他账号信息。
2. 不出现浏览器 Cookie、开发者工具或接口令牌。
3. 优先保留完整侧栏边界，让用户理解它位于浏览器右侧。
4. 发布前确认书摘正文适合公开展示。
5. 图片建议使用 PNG，并控制在宽度 1600px 以内。
